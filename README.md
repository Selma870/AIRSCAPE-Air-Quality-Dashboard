# 🌫️ AIRSCAPE — Air Quality Monitoring Dashboard

## ✨ Project Overview
AIRSCAPE merupakan proyek analisis dan visualisasi kualitas udara berbasis data pemantauan stasiun AQMS periode 1 Januari 2024–14 Oktober 2026.

Proyek ini berfokus pada analisis konsentrasi polutan, persistensi episode PM2.5, hubungan indikator kualitas udara dengan data kesehatan, serta evaluasi kualitas jaringan pemantauan.

## Project Structure
- `scripts/`: R scripts untuk preprocessing, quality control, analisis, dan ekspor data.
- `variable.md`: kamus variabel

## Tools
- R / RStudio
- Looker Studio
- Microsoft Excel

## 🚀 Dashboard Components
1. Air Quality Overview
2. The Episode of PM2.5
3. The Human Connection
4. Monitoring and Blind Spot & Strategic Action

## Reproducibility
Script disusun untuk mendokumentasikan tahapan pengolahan dan analisis data yang digunakan dalam pembangunan dashboard AIRSCAPE.

## Notes
Hasil analisis mengikuti keterbatasan, kelengkapan, dan karakteristik dataset yang digunakan dalam kompetisi.
